# Dashboard de Producción y Operatividad

Proyecto de análisis desarrollado en Power BI para consolidar y visualizar
información diaria de cuatro plantas de producción.

## Objetivo

Centralizar archivos operacionales con estructuras diferentes y crear
indicadores que facilitaran el seguimiento de producción, operatividad
y eventos de parada.

## Herramientas

- Power BI
- Power Query
- DAX
- Excel
- SharePoint

## Trabajo realizado

- Consolidación automática de archivos diarios.
- Normalización de nombres de plantas y fechas.
- Creación de un modelo de datos relacional.
- Desarrollo de indicadores de producción y operatividad.
- Clasificación automática de eventos.
- Diseño de segmentadores por planta, año, periodo y fecha.

## Indicadores principales

- Producción diaria y acumulada de petróleo, agua y gas.
- Stock en tanques y despacho.
- Horas operativas y horas de parada.
- Operatividad porcentual.
- Comparación entre producción real y capacidad objetivo.

## Resultado

El dashboard permite consultar el último día reportado y analizar
la evolución histórica por planta y periodo.

## Nota de confidencialidad

Proyecto demostrativo basado en un caso real. Los nombres, cifras y datos operacionales fueron modificados para proteger la confidencialidad del cliente.
